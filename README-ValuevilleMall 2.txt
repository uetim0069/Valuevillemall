# ValuevilleMall website prototype

Open `valuevillemall.html` in a modern browser to preview the responsive storefront.

## Included
- Responsive homepage inspired by the supplied reference
- Search and category filters
- Product cards and illustrative installment calculations
- Demo account creation/sign-in
- Demo dashboard with order list and payment progress
- Quality testing preview panel
- Order tracking timeline and map placeholder
- Demo state saved in browser localStorage

## Important
This is a frontend prototype, not a production commerce system. It does not collect money, verify payments, provide real authentication, stream live testing video, or show real driver GPS. Those features require a secure backend, payment-provider integration, product/test-video storage, and logistics/driver location integration. Installment pricing, eligibility, deposits, fees, contracts and disbursement rules should be confirmed before launch.
